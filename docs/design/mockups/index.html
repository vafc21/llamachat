Earlier round — the three structural options

A

Rail

An icon rail down the far left is the switcher. The sidebar next to it swaps contents per mode. Reads like a proper desktop app; the mode is always visible without hunting.

Switcher: left icon rail
BPicked

Segmented — chosen

Closest to your screenshots. One segmented control lives inside the composer and the sidebar has no toggle at all. Chat centres the greeting; Code docks the composer to the bottom.

Switcher: inside the composer
C

Command bar

Keyboard-first. Mode lives in the top bar with ⌘1/⌘2/⌘3, ⌘K opens a palette, no sidebar at all. A permanent status bar keeps CPU, RAM, GPU, VRAM and context on screen in every mode.

Switcher: top bar + ⌘K

What all three do differently from last time

  • One switcher, never two.
  • Zero emoji — single-weight line glyphs everywhere, including the tier badges.
  • Code shows no source code. It is a GUI over llama-cli: load lines, layer offload, KV cache, tok/s, sampler values, and file work rendered as one-line actions.
  • Context window is a ring next to the composer (A, B) or in the status bar (C).
  • CPU / RAM / GPU / VRAM as thin flat meters — no gauges, no glow.
  • The library is reachable from Code, with your real tiers (Quick / Smart / Best) and real hardware ratings (Blazing → Won't run).
  • Tool mode is called out in the Code composer so it's obvious the model has tools.
  • "Good evening, Vlad." kept, since that was the one thing you liked.
  • LlamaChat's own palette (#0d0d12 / #4d7cff), not Claude's warm charcoal and orange. No gradients, no glass, no neon.
