I want to build a command-line tool in Rust that watches a directory and runs tests when files change. What's the best approach?

Great choice! You'll want the notify crate for filesystem events. Here's the architecture I'd recommend:

use notify::{Watcher, RecursiveMode, watcher};
use std::process::Command;

fn main() {
    let (tx, rx) = std::sync::mpsc::channel();
    let mut watcher = watcher(tx, Duration::from_secs(1)).unwrap();
    watcher.watch("./src", RecursiveMode::Recursive).unwrap();
    
    for event in rx {
        Command::new("cargo").arg("test").status().unwrap();
    }
}

Key decisions: debounce strategy (batch events within a window), filter patterns (ignore .git and target/), and whether to run all tests or only tests related to changed files.

Can I also make it watch for config file changes and restart a dev server?

Absolutely. The cleanest approach is to make your watcher configurable through a watch manifest:

  • Each target defines a glob pattern + command to run
  • When files matching the pattern change → execute the associated command
  • Support per-target debounce windows (tests: 500ms, server reload: 200ms)

This pattern is how cargo-watch and watchexec work under the hood. You'd be building a simpler, more opinionated version — which is a great Rust learning project.
