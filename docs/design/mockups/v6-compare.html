Simple vs Developer

Same app, same build, one setting. LlamaChat asks once at startup and you can flip it any time in Settings. Both panels below are the live v6.html mockup — change the view and watch what disappears.

View

Just use it Default

No model names, no counters, no context. The app decides and gets out of the way.

Developer Opt-in

Everything visible: model, effort, tokens/sec, context, CPU · GPU · VRAM, plus Code.

What actually differs

ElementJust use itDeveloper
Workspaces Chat, Cowork Chat, Cowork, Code
Model control An Auto chip. No model is ever named. Named model + quantization, switchable per message
Effort / reasoning Router decides. One optional "prefer speed" switch. Set by hand, and the router's pick is shown with its reason
Context window Hidden. Trimmed and summarized silently. Ring by the composer + exact token count in the status bar
Throughput Hidden — just "Thought for 6 seconds" tok/s per reply and live in the status bar
System load Hidden CPU, RAM, GPU, VRAM meters, always on
Model library Not in the sidebar. Downloads happen on their own. Full library with tiers and hardware ratings
Status bar None Persistent, bottom of the window
Sidebar footer "Vlad · Local" "Vlad · Developer · 3 models"

How the routing works

Modelled on how ChatGPT works now. OpenAI describes GPT‑5 as a unified system: a fast model for most questions, a deeper reasoning model for hard ones, and a real-time router that picks between them per message based on conversation type, complexity, tool needs, and explicit intent — saying "think hard about this" pushes it to the reasoning path. The router is trained on real usage signals rather than hand-written rules. Users can override with Auto / Instant / Thinking, but Auto is the default and most people never touch it.

LlamaChat does the same thing locally. The tiers you already benchmark — Quick, Smart, Best — are the routing targets, and the per-machine ratings (blazing → won't run) bound what the router is allowed to pick. A short factual question goes to Quick at low effort; a multi-step technical question goes to Best at high effort. On the simple side that is invisible. On the developer side the same decision is printed above the reply: Router → Qwen3 30B A3B · high effort · reason: technical, multi-step.
