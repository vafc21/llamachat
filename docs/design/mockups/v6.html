Why does my 30B model slow to a crawl once the conversation gets long?

Thought for 6 seconds Router → Qwen3 30B A3B · high effort · reason: technical, multi-step

Because the KV cache grows with every token in the context, and once it stops fitting in VRAM it spills into system RAM. From that point every generated token has to cross the PCIe bus, which is far slower than on-card memory.

Three things usually fix it:

  • Lower the context size so the cache stays on the card
  • Quantize the KV cache to q8 instead of f16 — roughly halves it
  • Offload a few fewer layers so there's headroom left for the cache
